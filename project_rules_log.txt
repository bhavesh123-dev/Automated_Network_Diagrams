# Network Automation Project - Rules and Configuration Log
# Generated on: 2026-03-17
# This file documents all rules, configurations, and login methods used in the project

## Project Overview
This project automates Cisco network topology discovery and diagram generation using:
- Jump server for secure access (192.168.1.10)
- SSH tunneling to network devices
- CDP neighbor discovery
- Draw.io diagram generation with layout engines

## Login Methods

### Jump Server Access
- **IP**: 192.168.1.10
- **Username**: root (from JUMP_USERNAME env var or config.py default)
- **Password**: From JUMP_PASSWORD env var or config.py
- **Connection Method**: Paramiko SSHClient with AutoAddPolicy for host keys
- **Timeouts**: 10 seconds
- **Post-Connection Delay**: 2 seconds (jump server may be slow)

### Device Access
- **Username**: admin (from NET_USERNAME env var or config.py default)
- **Password**: From NET_PASSWORD env var or config.py
- **Connection Method**: SSH tunnel through jump server using direct-tcpip channel
- **Pre-Device Delay**: 1 second before attempting device login
- **Legacy Algorithm Support**:
  - KEX: Allows diffie-hellman-group1-sha1
  - Ciphers: Allows aes128-cbc, 3des-cbc, aes192-cbc, aes256-cbc
  - MACs: Allows hmac-sha1 and variants

### Commands Executed on Devices
1. `show version | include uptime` - Get hostname
2. `show version | include Cisco` - Get platform
3. `show cdp neighbors detail` - Get neighbor information
4. `show lldp neighbors` - Additional neighbor discovery
5. `show vlan-switch brief` - VLAN information
6. `show ip interface brief | exclude unassigned` - IP interface info
7. `show interface description | include up` - WAN switch connections

### Page Configuration
- PAGE_WIDTH: 1000 units
- PAGE_HEIGHT: 1400 units
- GRID_MARGIN: 60 units
- NODE_WIDTH: 130 units
- NODE_HEIGHT: 80 units
- TIER_SPACING_X: 200 units
- TIER_SPACING_Y: 180 units

### Layout Engines
1. **Graphviz Dot** (recommended):
   - Algorithm: hierarchical top-down
   - Prevents overlaps
   - Tier ordering: ["isp", "sdwan", "firewall", "wan_switch", "dist", "access", "server", "ap", "router"]
   - Requires: graphviz package

2. **Grid Layout** (fallback):
   - 6-page A4 grid (3x2)
   - Fixed positions per device type
   - Page-based placement following network hierarchy
   - No external dependencies

## Workflow

1. **Data Collection** (live_puller.py):
   - Read devices.csv or use seed devices
   - Connect to jump server (192.168.1.10)
   - SSH tunnel to each device with legacy algorithm support
   - Execute show commands (version, cdp neighbors, vlan, ip interface)
   - Parse interface descriptions for external connections
   - Save topology_data.json with device types and wan_connections

2. **Diagram Generation** (generate_diagram.py):
   - Load topology_data.json
   - Apply 6-page grid placement rules:
     - Page 1: ISP (external square box)
     - Page 2: SDWAN (top) → Firewall/WAN Switch (below)
     - Page 5: Distribution (upper half) → Access/AP (lower half)
   - Add external device connections with labeled links
   - Use appropriate shapes (Cisco for internal, squares for external)
   - Generate Draw.io XML with hierarchical layout
   - Save to output_diagrams/ with timestamp

3. **Automation** (scheduler.py):
   - Scheduled execution (default 60 minutes)
   - Optional GitHub upload for version control
   - Push to GitHub (optional)

## Troubleshooting

### Common Issues
- "Administratively prohibited": Jump server doesn't allow TCP forwarding
- "Authentication failed": Wrong credentials
- "No matching key exchange method": Device uses legacy algorithms
- "devices.csv not found": Wrong working directory

### Debug Steps
1. Test jump server connection manually
2. Test device connection through jump server
3. Check environment variables
4. Verify CSV file format
5. Check log outputs
