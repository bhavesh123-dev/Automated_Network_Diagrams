in topology_data.json

Logic : any cisco Switch which is not "Access switch" and can not be placed as access switch in Diagram
this switches can be "WAN Switch" , "Server Switch" , "other Switch"

Placement of this switches 
"WAN Switch" -- Below ISP and above SDWAN
"Access Switch" -- Below Distribution Switch
"Server Switch" and "other Switch" -- Place this Switch in same row of Distribution Switch , if two switches then one in right side and second in left side
any Switch is having NX-OS Plateform it is clear "Server Switch" no need further classification

patterns to Identify NON Access Switch

Access Switch pattern : 

Step 1 : get output of "show vlan brief" and have each vlan (example vlan 420) to check count #ignore vlan 1 always for step 2 
step 1 : Check with command " show interface status | count N" # Example " show interface status | count 420" #ignore vlan 1 always for counting 
step 3: if any single vlan is counting is  more than 10 times (except vlan 1) then it is confirm "Access Switch" 
also check command as OR operator "show running-config | count port-security|authentication" if count is more than 10 then it is confirm "Access Switch" 
" show interface status | count N" or "show running-config | count port-security|authentication" output greater than 10 always access switch

Step 4 : if any switch does not follow above pattern then identify it as non access switch Follow taks 4 to identify non CDP/LLDP neighbours and draw them in diagram as stated in below task 4
